*Solid Design — Play Toy*



**Date:** June 2026  

**Software:** Onshape  

**Tools used:** Sketch, Revolve, Plane



*Design Overview*

Designed a spinning play toy using axisymmetric solid modeling. A profile sketch was created and revolved 360° around a central axis to generate the toy's body, including the wide base disc, central stem, and rounded tip. An additional reference plane and sketch were used to define supporting geometry for the design.



*Feature breakdown*

| Feature    | Purpose |

| Sketch 1   | Profile defining disc, stem, and rounded top |

| Revolve 1  | Rotate profile 360° to form the axisymmetric solid |





*Skills demonstrated*

* Axisymmetric part design using Revolve
* Profile sketching with multiple connected curves
* Custom reference plane creation
* Practical toy/product design workflow
