# Complex Curved Surface — Surface Modeling

**Date:** June 2026  
**Software:** Onshape  
**Features used (22):** Transform, Loft, Ruled Surface, 
Fill, Delete Face, Mirror, Boolean, Sketch, Sweep

## Design Overview
A complex organic curved surface model demonstrating 
advanced surface modeling techniques in Onshape. 
The design uses multiple surface creation and 
manipulation tools to produce a smooth, 
multi-curvature solid body.

## Feature breakdown
| Feature | Purpose |
|---|---|
| Loft | Connect multiple profiles smoothly |
| Ruled Surface | Create developable surface between edges |
| Fill | Close open surface boundaries |
| Mirror | Symmetric geometry on both sides |
| Boolean | Merge surface bodies into one solid |
| Sweep | Extrude profile along a path curve |
| Delete Face | Remove and heal unwanted faces |

## Skills demonstrated
- Complex multi-step surface modeling workflow
- Combining surfaces using Boolean operations
- Symmetry using Mirror feature
- Organic shape creation beyond standard solid modeling
