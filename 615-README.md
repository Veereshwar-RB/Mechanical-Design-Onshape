## Wheel — Part Design
**Date:** June 2026  
**Software:** Onshape  
**Tools used:** Sketch, Revolve

### Design overview
Designed a wheel profile using a 2D sketch and the Revolve 
feature to generate the 3D solid body. The revolve tool 
rotates the sketch profile 360° around a central axis to 
produce a symmetric wheel geometry.

### Skills demonstrated
- 2D sketch with constraints and dimensions
- Revolve feature for axisymmetric parts
- Exported as STEP file for use in other CAD software
