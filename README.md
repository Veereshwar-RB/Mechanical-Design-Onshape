## 📁 File Structure

Each model in this repo contains three files:

| Extension | Contents |
|---|---|
| `.png` | Rendered screenshot of the completed model |
| `.mp4` | Screen recording of the full modeling process |
| `.step` | Exported STEP file — importable in any CAD software (CATIA, SolidWorks, Fusion 360) |
