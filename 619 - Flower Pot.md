*Solid Design* — Flower Pot



**Date:** June 2026  

**Software:** Onshape  

**Tools used:** Sketch, Offset, Loft, Shell


*Design Overview*

Designed a flower pot using a profile-based lofting technique.

A base sketch was created on the top plane, then offset four times to generate a series of replica profiles at different sizes. These profiles were connected using the Loft feature to form the tapered pot body, and the Shell feature was applied with a 4 mm wall thickness to hollow out the solid into a functional container.



*Feature breakdown*

| Feature | Purpose |

|---|---|

| Sketch | Base profile on the top plane |

| Offset (x4) | Generate scaled replica profiles for the taper |

| Loft | Connect all profiles into a smooth tapered solid |

| Shell (4 mm) | Hollow out the solid to create wall thickness |



*Skills demonstrated*

* Profile offsetting for controlled tapered geometry
* Multi-profile lofting
* Shell feature for hollow/functional part design
* Practical product design (flower pot) workflow
